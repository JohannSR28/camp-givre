# Camp Givré

Jeu de gestion de camp d'hiver en 3D isométrique (three.js), porté en application Next.js.

## Développement

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Structure

- `app/` — layout, page et styles globaux
- `components/Game.js` — HUD (composant client) qui démarre le jeu
- `lib/game.js` — logique du jeu et rendu three.js
- `Camp Givré.html` — version HTML d'origine
